# Μνήμη ανάκτησης με Standardised SQL

Κώδικας της πτυχιακής εργασίας «Σχεδίαση και Ανάπτυξη Μηχανισμών Μνήμης και
Ανάκτησης Πληροφορίας σε Μεγάλα Γλωσσικά Μοντέλα», Τμήμα Πληροφορικής και
Τηλεπικοινωνιών, Πανεπιστήμιο Θεσσαλίας.

Η εργασία επεκτείνει το [Xander](https://github.com/henrijsprincis/Xander) με
εξωτερικό μηχανισμό μνήμης βασισμένο σε ανάκτηση και εξετάζει στο Spider αν η
μορφή με την οποία αποθηκεύεται ένα λυμένο παράδειγμα επηρεάζει την ποιότητα της
ανάκτησης και την ακρίβεια εκτέλεσης. Η μεθοδολογία, τα αποτελέσματα και η
ερμηνεία τους περιγράφονται στην εργασία.

## Εκτέλεση

Τα scripts εκτελούνται μέσα από το αποθετήριο του Xander, από το οποίο
χρησιμοποιούν τα modules `eval.process_sql` και `open_ai.chat_gpt` και τις
βάσεις του Spider.

1. Κλωνοποίηση του Xander και αποσυμπίεση των βάσεων
   ```
   git clone https://github.com/henrijsprincis/Xander.git
   cd Xander
   pip install -r requirements.txt
   tar -xf database.zip
   ```
2. Αντιγραφή των scripts αυτού του αποθετηρίου μέσα στον φάκελο `Xander/` και
   εγκατάσταση των επιπλέον βιβλιοθηκών
   ```
   pip install -r requirements.txt
   ```
3. Δημιουργία αρχείου `.env` μέσα στον `Xander/`
   ```
   OPENAI_API_KEY=...
   HF_TOKEN=...
   ```
4. Εκτέλεση των scripts με τη σειρά της αρίθμησης
   ```
   python 1_load_data.py
   python 2_standardise_sql.py
   ...
   ```

## Περιεχόμενα

- `1_load_data.py` έως `24_column_order_check.py`: τα scripts, με τη σειρά
  εκτέλεσης. Κάθε script περιγράφει στην κεφαλίδα του τι κάνει, ποια αρχεία
  διαβάζει και ποια παράγει.
- `results/`: οι απαντήσεις του μοντέλου και οι πίνακες των αναλύσεων.

Τα ευρετήρια FAISS και τα αρχεία `.pkl` δεν περιλαμβάνονται και παράγονται εκ
νέου από τα scripts.
